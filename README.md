## What I care about

- **Privacy by architecture** — shipping tools where data never leaves the user's device.
- **Performance & accessibility** — fast loads, responsive from small screens up, accessible interactions.
- **Craft in the front end** — motion, typography, and 3D used deliberately, not decoratively.
